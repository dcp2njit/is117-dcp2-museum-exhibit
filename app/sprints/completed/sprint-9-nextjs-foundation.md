# Sprint 9: Next.js Foundation

**Goal:**
Initialize the Next.js rebuild and establish the application shell, route map, and shared design foundation.

**Scope:**
- In: project scaffolding, app router setup, base layout, navigation shell, global styles, route placeholders, TypeScript content models
- Out: final era copy migration, full page visuals, full source conversion

**Tasks:**
- Create the Next.js project structure for the exhibit rebuild
- Configure App Router, TypeScript, and static-export-ready settings
- Build the shared shell: layout, header, footer, skip link, metadata baseline
- Create route placeholders for home, four eras, and sources
- Define initial content model types for eras, archive items, context blocks, and sources
- Establish the first pass of design tokens for spacing, typography, color, and page width

**Files to touch:**
- New Next.js app workspace or rebuild directory
- App layout and route files
- Shared component files
- Content model files
- Global styles and configuration files
- nextjs-rebuild-spec.md if implementation decisions sharpen the contract

**Acceptance Criteria:**
- Next.js project runs locally and builds successfully
- Shared site shell exists and is wired into all planned routes
- Route placeholders exist for all primary pages
- Initial content model types are defined and usable
- Global style tokens and baseline typography are established

**Verification Checklist:**
- [ ] App runs locally
- [ ] Build succeeds
- [ ] Shared layout renders across all primary routes
- [ ] Route structure matches the rebuild spec
- [ ] Initial content types compile cleanly
